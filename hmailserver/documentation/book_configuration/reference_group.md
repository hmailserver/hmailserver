## General

### Group name

<div class="indented">The name of the group can be anything you like.</div>

### Members

<div class="indented">Under Members, add the accounts you want to be member of this group.</div>

 

 

### Example of usage

I have a team of sales people. I add each of them to the 'sales' group.  

  

I set up some IMAP public folders, say 'incoming', 'pending' and 'finalised' and give the group appropriate permissions.  

  

When a new staff member joins the sales team, or someone leaves, I merely update the 'sales' group with the modified members. The alternative would be to go through each of the public folders and set explicit permissions for each new person and remove old permissions.
