### Connections

<div class="indented"> This setting defines the maximum number of simultaneous connections that will be allowed to the POP3 server. If zero is specified, an unlimited number of connections will be allowed. </div>

### Welcome message

<div class="indented"> The welcome message is sent to POP3 clients directly after they connect to the server. One reason to change the welcome message is to make it harder for others to determine what server software you are running. </div>
