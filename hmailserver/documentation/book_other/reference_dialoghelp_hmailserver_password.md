### What is "hMailServer Password"?

When you connect to hMailServer using hMailServer Administrator, and when you perform a database upgrade, you will be prompted for the hMailServer Password.

This is the password for your hMailServer installation, which you set during the installation process. This password may have been changed later using hMailServer Administrator, under *Settings - Advanced*.

Please note that this is not the same as the password for your database.
