### Description

The aliases object is a collection of all aliases connected to a specific domain.

### Methods

<div class="api_method_name">Add()</div>

<div class="api_description">Adds a new alias to the collection.</div>

<div class="api_method_name">Delete(long Index)</div>

<div class="api_description">Deletes the alias with the specified index.</div>

<div class="api_method_name">DeleteByDBID(long DBID)</div>

<div class="api_description">Deletes an alias by its given database identifier.</div>

<div class="api_method_name">Refresh()</div>

<div class="api_description">Refreshes the collection.</div>

### Properties

<div class="api_method_name">long Count</div>

<div class="api_description">Returns the number of aliases in the collection.<br> <i>(read-only)</i></div>

<div class="api_method_name"><a href="?page=com_object_alias">Alias</a> Item(long Index)</div>

<div class="api_description">Returns a alias by a given index.<br> <i>(read-only)</i></div>

<div class="api_method_name"><a href="?page=com_object_alias">Alias</a> ItemByDBID(long DBID)</div>

<div class="api_description">Returns an alias by its given database identifier.<br> <i>(read-only)</i></div>

<div class="api_method_name"><a href="?page=com_object_alias">Alias</a> ItemByName(string Name)</div>

<div class="api_description">Returns an alias by it's name.<br> <i>(read-only)</i></div>
