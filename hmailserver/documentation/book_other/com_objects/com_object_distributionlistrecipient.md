### Description

The Recipient object represents a single recipient in a hMailServer distribution list.

### Methods

<div class="api_method_name">Delete()</div>

 

<div class="api_description">Deletes the recipient from the distribution list.</div>

 

<div class="api_method_name">Save()</div>

 

<div class="api_description">Saves the recipient in the database.</div>

 

### Properties

<div class="api_method_name">long ID</div>

 

<div class="api_description">The unique database identifier for the recipient.<br>
<i>(read-only)</i></div>

 

<div class="api_method_name">string RecipientAddress</div>

 

<div class="api_description">The email address of the recipient.</div>
